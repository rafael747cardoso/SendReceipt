


A. Resend account setup - OK

Sign up at resend.com (free, no credit card)
Verify your email domain (or use their onboarding domain for testing)
Create an API key → copy it


B. Build the Shiny app locally - OK

Create a project with app.R containing:
	fileInput (with accept = "image/*" and capture = "environment" for phone camera)
	dateInput
	three selectInputs (establishment type, name, purchase type)
	actionButton to send 
		On button click
			read the uploaded photo
			base64-encode it
			POST to Resend's /emails endpoint via httr2 with the image as attachment and metadata in the subject/body
Store the API key in an .Renviron file locally (RESEND_API_KEY=re_xxxxx)


C. Push to GitHub - OK

Create a public repo on GitHub
Add .Renviron to .gitignore (never commit your API key)
Push app.R and a manifest.json (generated by rsconnect::writeManifest())


D. Deploy to Posit Connect Cloud

Sign in at connect.posit.cloud
Click Publish → link your GitHub repo
Go to Settings → Environment Variables → add RESEND_API_KEY with your key
Deploy — you get a public URL


E. Phone setup

Open the URL on your phone browser
Add to home screen
Snap receipt → pick categories → tap send → done
